# ML Affiliate AI

Sistema automatizado de afiliados com backend, frontend e configuração para Render.

## Estrutura
- `backend/` — API NestJS/TypeScript
- `frontend/` — painel web
- `render.yaml` — Blueprint do Render
- `Dockerfile` — imagem de execução

## Segurança
Segredos e tokens devem ser configurados como variáveis de ambiente. Nunca coloque credenciais reais no GitHub.

## Deploy
O projeto está preparado para deploy no Render usando `render.yaml`.
